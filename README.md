# Skyline Plastics Maintenance Documents

Maintenance documentation for the Skyline Plastics plants in the Great Lakes territory (Dayton, Toledo,
Fort Wayne). Fictional sample data for a proof of concept.

## Folders
| Folder | Status |
|---|---|
| `approved/` | **Controlled documents.** Reviewed and approved by the maintenance lead. The only source of truth. |
| `drafts/` | Proposed revisions under review. Not approved. |
| `archive/` | Superseded or withdrawn documents, kept for audit. Not valid. |
| `vendor/` | Supplier marketing material. Not a service document. |
| `training/` | Informal training notes. Not reviewed. |
| `meeting-notes/` | Meeting notes. Not procedures. |

## Branches
Only `main` is published. Other branches hold work in progress, vendor submissions and plant-local
proposals that have not been approved.

## Changing a controlled document
Open a pull request to `main` that changes a file under `approved/`. The maintenance lead reviews and merges.
